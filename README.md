# timberfeller-site

The website for Timber (tree felling in the Madoc and Ottawa areas of Ontario), served by GitHub Pages at https://timberfeller.ca.

- `index.html`: the main page (text-for-a-quote first)
- `privacy.html`: the privacy policy (also used for the Google app's Branding page)
- `style.css`, `img/`: styles and images
- `CNAME`: the custom domain
